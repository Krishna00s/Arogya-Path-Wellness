# Arogya Path Wellness — Project Blueprint

**Status:** Planning / decisions subject to owner approval. **Legal entity:** Arogya Path Marketing. **Brand:** Arogya Path Wellness.

Build a responsive, accessible, affordable Ayurvedic/herbal, wellness, supplements and healthcare e-commerce storefront. Aim for **500 concurrent browsing users** (must be load-tested) and **1,000+ customer accounts** (not an account ceiling). Minimize ongoing cost **without compromising payment integrity, privacy, backups or security**.

## Documents
1. `01-product-and-flows.md` — scope, pages, checkout, admin.
2. `02-ui-ux.md` — visual direction, responsive behavior, accessibility.
3. `03-architecture-and-data.md` — stack, API boundaries, schema, infrastructure.
4. `04-security-payments-operations.md` — OTP, payment security, deployment and tests.
5. `05-build-plan-and-decisions.md` — implementation stages, open questions and acceptance gates.
6. `AGENTS.md` — instructions to Antigravity.

## How to use
1. Read and approve the **Open decisions** in document 05.
2. Put these files in the repository's `docs/` directory, with `AGENTS.md` at repository root.
3. Ask Antigravity to implement **only the next approved milestone**, not the entire project in one prompt.
4. Review code, run tests, and record architectural changes in these docs.
